# AURA · 桌面动态背景

把桌面壁纸换成会呼吸的画面：**深空星云 / 抽象流体 / 极简网格** 三套场景，
右键托盘图标随时切换，免安装、不占任务栏、不挡图标。

- 平台：Windows 10 / 11（x64）
- 形态：单个 `AURA.exe`，直接铺在桌面图标下面（不是覆盖全屏的假壁纸）
- 依赖：系统自带的 .NET Framework 4.8 与 Edge WebView2 运行时（Win10/11 默认就有）
- 渲染：WebGL2 程序化着色器，无贴图、无网络请求、无第三方库

## 两种形态

| 形态 | 内容 |
|---|---|
| 桌面动态背景 | 三套场景铺在桌面图标下面，托盘随时切换 |
| NEXUS 监控台 | 托盘右键「打开监控台」，全屏展示五种引擎 + 五个接收端 + 六个真实看板 |

监控台由本机 127.0.0.1 的采样服务供数（仅本机可访问），数据全部来自真实系统指标。

## 自动更新

托盘右键 →「检查更新」，从 NAS 的 `https://www.topbei.cn/aura/update.json` 读取新版本（外网不通时自动改试局域网 `http://192.168.1.6/aura/update.json`），
下载后校验 SHA-256，替换文件并自动重启。默认启动 12 秒后静默检查一次。

- 更新源可在 `%APPDATA%\AURA\settings.json` 的 `UpdateUrl` 改成别的地址。
- 发布新版本：`python3 tools/publish_update.py <zip> --version 1.1.0 --notes "说明"`。

## 快速开始

1. 解压整个文件夹到任意位置（不要只把 exe 单独拷出来）。
2. 双击 **`AURA.exe`**，桌面会立即变成动态背景，右下角托盘出现 AURA 图标。
3. 右键托盘图标 → 场景 / 配色 / 动效强度 / 帧率 / 开机自启 / 退出。

## 三套场景

| 场景 | 画面 | 特点 |
|---|---|---|
| 深空星云 | 斜穿桌面的银河带、尘埃暗纹、星点闪烁 | 大片近黑留白，图标清晰 |
| 抽象流体 | 缓慢流动的丝绸光带（极光感） | 冷蓝 + 主题色 + 冷紫，层次柔和 |
| 极简网格 | 细网格 + 错峰扩散的脉冲环 + 扫描线 | 克制、工程感，适合长时间看 |

## 四套配色

冷白银 `#D2DCE5`、香槟金 `#CBB68A`、深海蓝 `#43A9CF`、星云紫 `#AFA2D9`。
配色只改变画面本身的颜色（着色器里的光带、脉冲、星云色），不是整页滤镜。

## 会跟着电脑负载变化

每秒采样一次真实 CPU / 内存 / 网络吞吐，合成 0–1 的负载系数，
轻微影响星云脉动、光带流动速度与脉冲亮度——**只是氛围调制，不是仪表盘**，
托盘菜单里可以关掉「跟随电脑负载」。

## 省电设计

- 默认帧率上限 30（可选 24 / 30 / 60）。
- 检测到全屏应用（游戏、视频）自动暂停动效，退出全屏后恢复。
- 窗口不可见时停止渲染。

## 常见问题

**桌面没变？** 看同目录 `aura.log`；多半是 Explorer 未运行或被杀软拦了 SetParent。

**提示缺少 WebView2 运行时？** 装一次即可（Win10/11 一般都自带）：
<https://developer.microsoft.com/microsoft-edge/webview2/> 选 Evergreen Standalone (x64)。

**想暂时关掉？** 托盘菜单 → 暂停动效；要彻底退出选「退出 AURA」。

**和 Wallpaper Engine 冲突？** 两者都往桌面层挂窗口，建议只留一个。

## 目录结构

```
AURA.exe            主程序
*.dll               WebView2 托管库与加载器
web/                三个场景的着色器与页面
aura.log            运行日志（排查用）
使用说明.txt        给不熟悉命令行的人看
```

## 从源码构建

```bash
dotnet build host/AURA.csproj -c Release -o dist/AURA
```

GitHub Actions 会自动构建并附带自检（WebView2 初始化 + 三个场景着色器编译），
产物为 `AURA-v1.0.0-win64.zip`。
